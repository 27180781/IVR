# חיוג יוצא (DISA)

מתקשר שמגיע לתפריט מקיש **3**, מזדהה בקוד, מקיש מספר יעד — והמערכת מחייגת
אליו ומחברת ביניהם.

> **קראו את פרק האבטחה לפני שאתם מפעילים.** התכונה הזו מאפשרת למי שמגיע
> לתפריט לחייג לכל מקום בעולם **על חשבונכם**. זה הווקטור המנוצל ביותר
> בטלפוניה, וסורקים מוצאים מערכות פתוחות תוך ימים.

---

## הזרימה

```
תפריט ראשי ─ 3 ─► קוד גישה ─► מספר יעד ─► חיוג ─► שיחה מחוברת
                      │              │            │
                   3 טעויות      לא מורשה      תפוס / אין מענה
                      ▼              ▼            ▼
                    ניתוק      חזרה למספר    חזרה למספר
```

המתקשר מקיש את היעד **עם קידומת בינלאומית**. המערכת מקבלת כל צורה נפוצה:
`00972…`, `011972…`, `972…` או `+972…` — וגם עם מקפים ורווחים.

---

## הפעלה

### 1. הגדרת Termination בטוויליו

בלי זה כל שיחה יוצאת תידחה, והדחייה לא תסביר למה.

Console → Elastic SIP Trunking → הטראנק → **Termination**:

1. הגדירו **Termination SIP Domain**, למשל `your-trunk.pstn.twilio.com`
2. **Authentication → IP Access Control List** → הוסיפו את ה‑IP של השרת

טוויליו לא מאמתת בסיסמה בכיוון היוצא — הזיהוי הוא לפי כתובת IP. בלי ה‑ACL
היא לא תקבל מכם שיחות בכלל.

### 2. הגדרת השרת

ב‑`asterisk/asterisk.env`:
```bash
TWILIO_TERMINATION_DOMAIN=your-trunk.pstn.twilio.com
```
```bash
sudo ./scripts/deploy-asterisk.sh
```

ב‑`.env` — אם הקובץ נוצר לפני שהתכונה נוספה, המפתחות פשוט לא שם:
```bash
sudo ./scripts/sync-env.sh    # מוסיף הגדרות חדשות, לא נוגע בקיימות
```
ואז:
```bash
OUTBOUND_ENABLED=true
OUTBOUND_PIN=4821                  # 4-12 ספרות
OUTBOUND_ALLOWED_PREFIXES=+972     # רשימת קידומות מותרות
OUTBOUND_CALLERID_MODE=trunk
OUTBOUND_MAX_DURATION_SEC=600
```
```bash
sudo systemctl restart ivr-app
```

**האפליקציה תסרב לעלות אם `OUTBOUND_ENABLED=true` בלי `OUTBOUND_PIN`.** זה
מכוון: תקלה רועשת עדיפה על שירות חיוג פתוח שאיש לא שם לב שהופעל.

### 3. הקלטות

עשר הודעות חדשות. `npm run prompts:list` מדפיס את הרשימה — וגם **הודעת
התפריט הראשי השתנתה** ומזכירה עכשיו את אפשרות 3, אז צריך להקליט אותה מחדש.

## הזיהוי היוצא — מה באמת אפשרי

זו הנקודה החשובה, ויש בה מגבלה שלא תלויה בקוד.

| מצב | מה היעד רואה |
|------|---------------|
| `trunk` | המספר שאליו התקשרו אליכם. **תמיד עובד.** |
| `original` | המספר של המתקשר עצמו. עובד רק אם הוא מאומת אצלכם — ראו למטה. |
| `fixed` | תמיד `OUTBOUND_CALLERID_NUMBER`. |

**טוויליו לא מאפשרת זיהוי שרירותי.** היא מקבלת מספר ב‑`From` רק אם הוא
**בבעלות החשבון שלכם** או רשום כ‑**Verified Caller ID**. מספר אחר יידחה או
יוחלף. זו מגבלת ספק (ורגולציה — STIR/SHAKEN), לא משהו שאפשר לעקוף בקוד.

כלומר `original` עובד עבור **קבוצה ידועה של מתקשרים** שתאמתו מראש:
Console → Phone Numbers → **Verified Caller IDs** → Add. לכל מספר אחר,
המערכת נופלת אוטומטית למספר שאליו התקשרו — במקום להכשיל את השיחה.

אם `OUTBOUND_CALLERID_NUMBER` ריק, ברירת המחדל היא **המספר שאליו חייגו**.
הוא בבעלותכם בהגדרה, ולכן תמיד תקין — ואין מה להגדיר.

## אבטחה

שלוש שכבות, וכל אחת מהן לבדה לא מספיקה:

**1. כבוי כברירת מחדל.** `OUTBOUND_ENABLED=false`.

**2. קוד גישה.** חובה. שלוש טעויות ← ניתוק. הקוד עצמו **לא נשמר בלוג
השיחות** — רק מספר הניסיונות. השוואה בזמן קבוע.

**3. רשימת קידומות.** `OUTBOUND_ALLOWED_PREFIXES=+972,+1` — רק ישראל
וארה"ב. **ריק פירושו כל העולם**, וזה בדיוק ממה שעשויות חשבוניות ההונאה.
הגדירו את זה.

ובנוסף: `OUTBOUND_MAX_DURATION_SEC` חוסם שיחה תקועה מלחייב ללא הגבלה, וכל
ניסיון חיוג נרשם עם המתקשר, היעד והתוצאה.

### מה לנטר

בלוח הבקרה, שיחות שמסלולן כולל `placeCall`. חפשו:

- ניסיונות PIN כושלים חוזרים ממספר לא מוכר
- יעדים בקידומות שלא ציפיתם להן
- חיוג בשעות שבהן איש לא אמור להשתמש במערכת

**החליפו את ה‑PIN מדי פעם**, ובוודאות אם הוא נמסר למישהו שכבר לא צריך אותו.

## בדיקה

```bash
journalctl -u ivr-app -f | grep -i "dialling out\|outbound"
```

התקשרו, הקישו 3, את הקוד, ואת היעד. בלוג תראו:

```
"msg":"dialling out","destination":"+972…","endpoint":"PJSIP/+972…@twilio",
"callerId":"+1…","mode":"trunk"
```

ואם היעד ענה:
```
"msg":"outbound call connected"
```

### תקלות

| מה קורה | הסיבה |
|---------|--------|
| כל שיחה יוצאת נכשלת מיד | Termination לא מוגדר, או ה‑IP לא ב‑ACL |
| `no caller ID could be resolved` | `OUTBOUND_CALLERID_NUMBER` ריק והמספר הנכנס לא ב‑E.164 |
| היעד רואה מספר אחר ממה שציפיתם | `original` עם מספר שאינו מאומת — טוויליו החליפה אותו |
| "חיוג ליעד זה אינו מורשה" | הקידומת לא ב‑`OUTBOUND_ALLOWED_PREFIXES` |
| האפליקציה לא עולה | `OUTBOUND_ENABLED=true` בלי `OUTBOUND_PIN` — זו התנהגות מכוונת |
