# קבצי אודיו

הקבצים עצמם **לא** נשמרים בגיט — הם בינאריים, כבדים, ומשתנים בקצב אחר
מהקוד. מקור האמת לרשימה הוא `src/ivr/prompts.ts`.

```bash
npm run prompts:list
```

## איפה הם יושבים בשרת

```
/var/lib/asterisk/sounds/he/
├── ivr/            ההודעות של המערכת (welcome, main-menu, ...)
└── digits/         ערכת הצלילים העברית: 0-9 והמספרים
```

הנתיב שבקוד הוא **יחסי לתיקיית השפה**: ניגון של `ivr/welcome` על ערוץ
שהשפה שלו `he` טוען את `/var/lib/asterisk/sounds/he/ivr/welcome.wav`.
זה מה שיאפשר להוסיף שפה נוספת בלי לגעת בקוד — רק תיקייה מקבילה.

## פורמט

WAV, PCM 16-bit, **8000 Hz, mono**. הטלפוניה דוגמת ב-8kHz בכל מקרה;
קובץ ב-44.1kHz רק יגרום לאסטריסק להמיר בזמן אמת ולשרוף CPU לכל שיחה.

```bash
ffmpeg -i source.mp3 -ar 8000 -ac 1 -c:a pcm_s16le output.wav
```

## `digits/` — הערכה העברית

הקראת מספרים (`digits:123456`) נשענת על קבצי הספרות של אסטריסק בשפה
העברית. הם אינם חלק מההתקנה הסטנדרטית ויש להשיג או להקליט אותם בנפרד.
המינימום לזרימה הנוכחית הוא `0.wav` עד `9.wav`.

בלעדיהם, המערכת תשמיע את ההודעות הקבועות אבל תשתוק במקום להקריא את מספר
ההזמנה.
